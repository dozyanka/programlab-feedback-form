# FormLab – форма обратной связи

Адаптивная форма обратной связи на **PHP 8.2+ / JavaScript / CSS**. Выполнена в качестве тестового задания на позицию PHP-разработчика (Middle/Senior).

## Что умеет

- Тема (select), ФИО, телефон, e-mail, сообщение, CAPTCHA, согласие на обработку персональных данных и скрытое поле `action=message`.
- Двойная валидация: JavaScript перед отправкой и PHP независимо от JavaScript; ошибки рядом с полями и общее уведомление.
- Обязательность всех полей, проверка формата российского телефона и e-mail, ограничения **255 символов для текстовых полей** и **4096 для сообщения**.
- Отправка через **Fetch API / AJAX** без перезагрузки, маска номера `+7 (999) 123-45-67`.
- Авторская графическая CAPTCHA, привязанная к PHP-сессии, одноразовая и действующая 5 минут, с кнопкой обновления.
- После успешной валидации письмо отправляется **на e-mail, введённый посетителем**.
- Адаптивная вёрстка, индикация загрузки, клавиатурная навигация.

## Быстрый запуск через Docker

Нужны **Docker Desktop** (с запущенным движком) и Docker Compose V2.

```powershell
docker compose up --build -d
```

Затем откройте:

| Адрес | Назначение |
|---|---|
| `http://localhost:8080` | Форма обратной связи |
| `http://localhost:8025` | Mailpit: интерфейс тестовой почты |

```powershell
# Просмотр логов
docker compose logs -f web

# Проверка PHP и запуска тестов внутри контейнера
docker compose exec web php tests/run.php

# Остановить сервисы
docker compose down
```
